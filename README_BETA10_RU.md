# KenshiShop 1.0 beta.10

Полностью закройте Kenshi, сделайте копию сохранения и замените `mods/KenshiShop` папкой из полного архива. `KenshiShop_LegendaryCompat` нужен с Legendary of Kenshi.

Начальник охраны проверяет текущий состав города и может показать подтверждённые потери даже при повреждении старого реестра найма. При полной проверке без потерь он отвечает «Все на месте». Если известна только часть состава, диалог сообщает об этом.

При загрузке мод восстанавливает целые записи об оплате из многократно упакованных полей старых beta.6–beta.8. Если платёжная история обрезана слишком сильно, мод сохраняет аварийную запись и блокирует платные действия. Дополнительный патруль из трёх NPC стоит 20 000 кат разово. Замена одного сотрудника стоит 10 000 кат.

Максимальное HP головы рабочего улья восстановлено до 125, солдата до 200. У принца улья максимальное HP каждой части тела равно 80. Изменения применены к расам KenshiShop в FCS. Состояние ран остаётся в файлах сохранения.
