KenshiShop alpha.88 — исправление двойного преобразования координат служебных узлов. Полный мод, тестовая сборка.

- Раньше Lua передавала мировую позу, после чего фабрика повторно применяла положение и поворот здания. Теперь ей передаются масштабированный локальный сдвиг и исходный локальный поворот.
- Диагностика проверяет фактическую позицию выбранного поста относительно исходной планировки и отдельно показывает этаж. Непустого handle недостаточно для положительного вывода о геометрии.
- Работающий патруль, состав FCS-пакетов, назначение городов, мебель и ассортимент сохранены. Файл .mod полностью побайтно совпадает с alpha.87.

Проверены 108 Lua-файлов, 61 сценарий API и восстановление контроллера, сохранность бинарных данных, 72 исходных записей узлов и защищённых файлов. **Kenshi здесь не запускалась; выполнение ролей нужно подтвердить. Назначение этажа верхним узлам ещё не исправлено.**

Полностью закройте игру, сохраните копию сохранения/мода и замените папку KenshiShop целиком из FULL.zip. Перепризывать NPC не нужно. После 5–10 игровых минут пришлите лог с NPC_WORK_AUDIT88. Подробности: README_ALPHA88_RU.md.
