# KenshiShop 1.0 beta.12

- Кадровая обработка использует актуальные ссылки на отряды и приостанавливается при загрузке, сбросе и выходе.
- Устранена подмена штатного жильца башни при создании дополнительного патруля.
- Уже оплаченные отряды подхватываются по штатным идентификаторам. Заказ завершается после назначения задач, а восстановление само по себе не списывает кат.

Полный ZIP включает основной мод и папку совместимости с Legendary of Kenshi. Подробности в `README_BETA12_RU.md`.
