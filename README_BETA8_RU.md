# KenshiShop 1.0 beta.8

В beta.7 дважды загрузилось поле реестра размером ровно 4 095 байт с ошибкой длины. В новой версии каждая часть занимает до 3 000 байт. Общая длина и контрольная сумма проверяются до использования реестра. Целые старые реестры переходят в новый формат при следующем сохранении. Для восстановления уже обрезанных данных нужна исходная целая копия. При повреждении данных диалог доступен, а оплата заблокирована.

Монитор доставки больше не останавливается, если NPC, который ранее не мог принять команду, готов отправиться к зданию. В обычном журнале постов остаются первые назначения, смены дежурств и сообщения о проблемах. Для подробностей в текущем сеансе введи `KS.postTrace(true)` в консоли KenshiLua. `KS.postTrace(false)` снова отключает подробности.

Удалены старая утилита очистки миниатюр, три заметки alpha.80 из папки мода, дубль координат полицейских узлов, старый обработчик списка погибших и неиспользуемый кэш NPC. Поиск потерь доступен через диалог начальника. Все 84 ресурса персонажей используются игровыми записями, в том числе через материалы моделей. Шаблоны и ID, на которые могут ссылаться сохранения, включены в архив.

1. Закрой Kenshi и сделай копию сохранения.
2. Замени папку `mods/KenshiShop` целиком содержимым полного ZIP.
3. Папку `KenshiShop_LegendaryCompat` используй только с Legendary of Kenshi. Загружай совместимость после обоих модов.
4. Загрузи игру. Версию можно проверить командой `KS.status()`. Для проверки найма открой диалог начальника и проверь результат после сохранения и повторной загрузки.

Автоматические тесты проверяют код и данные. FPS и прежний вылет в игре остаются непроверенными.
