# KenshiShop 1.0 beta

Версия для логов и архива: `1.0-beta.1`. Основа — alpha.91, в которой пользователь подтвердил работу постов, патруля, переноса в кровать и блокировки отсечения.

## Установка

1. Полностью закройте Kenshi.
2. Сохраните копию прежнего мода и сохранения.
3. Замените папку `Kenshi/mods/KenshiShop` целиком папкой из `KenshiShop_1.0-beta.1_FULL.zip`. Копирование поверх старых файлов оставит удалённые модули на диске.
4. Если используется Legendary of Kenshi, установите `KenshiShop_LegendaryCompat` и поставьте его после обоих модов. Без Legendary этот патч не включайте.
5. Запустите игру с прежними KenshiLua/KenshiLib. Дополнительных замен игровых DLL не требуется.

Мебель, ассортимент, расовые характеристики, штатные пакеты ИИ, доставка и маршруты сохранены. В FCS заменено только описание версии; все 227 игровых записей основного мода сохранены. Все 73 записи совместимости также сохранены.

## Изменения беты

- Исправлен поиск старых личных задач при миграции с alpha.82/.83: учитываются пять очередей приоритетов. Чужие задачи с совпадающим номером сохраняются.
- Диагностика защиты конечностей больше не теряет события из-за ограничения частоты сообщений. Накопленные блокировки выводятся после паузы; учтены откат времени и сброс нативных счётчиков.
- Удалены четыре неиспользуемых Lua-модуля и невызываемые функции прежнего управления Move/Idle. Подробности: `AUDIT_BETA1_RU.md`.
- Версия обновлена в консоли, стартовом логе, описании мода и документации. Из справки убраны устаревшие сообщения о выключенной работе NPC.

## Диагностика

В начале лога должна быть версия `1.0-beta.1`.

- `NPC_NOSEVER91_READY ... native_guard=ACTIVE` — NPC зарегистрирован для защиты.
- `NPC_NOSEVER91_BLOCKED ... amputations=N crushes=M` — нативный перехватчик заблокировал попытки отсечения/разрушения. Счётчики накопительные за время жизни регистрации, повторные строки суммировать нельзя.
- `NPC_NOSEVER91_FAILED` — защита не подтверждена, причина указана в строке.

Номера 89/90/91 в диагностических событиях оставлены для совместимости с разбором логов; это не номер установленной версии. Защита не лечит повреждения и не возвращает ранее утраченные конечности.

Полезные команды встроенной консоли KenshiLua: `KS.help()`, `KS.status()`, `KS.npcReport()`, `KS.npcLogs(120)`.

## Проверки и ограничения

Синтаксис 109 Lua-файлов, 105 сценариев API и отдельная проверка контроллера пройдены. Проверены ссылки FCS, достижимость модулей, ресурсы и состав полного архива. DLL не менялась: её исходники/бинарный хеш сверены с Windows-сборкой alpha.91; Windows-проба выполняется отдельно в CI.

Kenshi в рабочей среде разработчика не запускается. Эти проверки не заменяют игрового теста беты. Результат alpha.91 в присланных пользователем данных: два события блокировки отсечения, у 15 NPC защищённых рас в сохранении отсутствующих/разрушенных конечностей не обнаружено.

`Development/NativeBridge` — соответствующие исходники, SDK-заголовок, проверки и GPL-3.0 для нашей DLL. Они не загружаются игрой. Остальные инструменты разработки и история доступны в репозитории.
