# KenshiShop 1.0 beta.2

Полный мод, версия в логе `1.0-beta.2`.

## Изменения

Для бармена, продавцов оружия/доспехов/инженерных товаров/протезов, охранников обоих этажей, начальника и всех патрульных применяется одна схема:

| Уровень | Задачи |
|---|---|
| 3 | Medic58, Robotics57: лечение/ремонт себя и союзников; защита отряда143 и союзников в городе288 |
| 2 | Rescue148: подбор раненого; CarryToBed106: перенос и укладывание в подходящую кровать |
| 1 | Торговля20, открытие дверей86, пост51, охрана268/38, патруль36, следование141, ночное возвращение239 |

Защита и лечение остаются на одном уровне. Гарантии «всегда сначала бой» эта схема не даёт: выбор между срочными задачами делает штатный ИИ. Уровень 4 приказов движка и уровень 0 отдельных действий не используются для наших рабочих задач.

Рабочие определения задач созданы отдельно для KenshiShop: ванильные задачи глобально не изменяются. Сохранён вес 110 нативного переноса: он действует внутри уровня 2 и не поднимает спасение над срочным уровнем 3.

## Существующие NPC

Новые пакеты `KSB2 …` заменяют `KS90 …` и более старые пакеты после завершения боя, медицинских действий и переноса. Замена происходит один раз, без пересоздания NPC и принудительного обновления товаров. Если отряд занят, обновление откладывается до безопасного состояния.

Старые личные посты KenshiShop переводятся с приоритета 2 в приоритет 1 переносом того же объекта задачи в соответствующую нативную очередь. Уже правильные посты не пересоздаются. Старые продолжения переноса обрабатываются отдельно после завершения текущего действия; приказы и посторонние задачи не сбрасываются целиком.

## Что сохранено

- Мебель, модели, текстуры, расовые характеристики и ассортимент.
- Этажи охранников и смена постов каждые 30 игровых минут.
- Магазины 06:00–23:00; бар/протезы 24 часа.
- Дневной патруль и ночные посты под башней; дневной уличный/ночной внутренний пост начальника.
- Родной город, выбранный город службы, доставка NPC и пополнение аптечек/ремкомплектов.
- Тот же проверенный KenshiShopNative.dll и защита конечностей 14 кастомных рас.

## Установка

1. Полностью закройте игру и сохраните резервную копию сохранения/прежнего мода.
2. Замените папку `Kenshi/mods/KenshiShop` целиком из `KenshiShop_1.0-beta.2_FULL.zip`.
3. С Legendary of Kenshi также установите `KenshiShop_LegendaryCompat` после обоих модов. Без Legendary этот патч не включайте.
4. Запустите игру с прежними KenshiLua/KenshiLib. Дождитесь завершения текущих действий NPC.

Пересоздавать NPC для обновления не нужно. Сохранение не изменяется установщиком: обновление происходит через игровые API во время работы мода.

## Проверка

`KS.status()` показывает версию; `KS.npcReport()` и `KS.npcLogs(120)` — состояния отрядов.

- `NPC_ROLE_READY ... label=KSB2 ... urgent=3 rescue=2 work=1` — новый пакет назначен.
- `NPC_POST_DUTY90 ... JOB_ASSIGNED ... priority=1` — нативная очередь поста проверена.
- `NPC_WORK_AUDIT90 ... active=… priority=…` — фактическая выбранная задача и прочитанный приоритет.
- `NPC_RESCUE90 ... carry_priority=2` — наблюдаемое продолжение переноса уровня 2.
- `BED_CONFIRMED` требует нативного подтверждения кровати; освобождение рук само по себе успехом не считается.

Номера90/91 в событиях оставлены для чтения прежних логов; актуальная версия —1.0-beta.2.

Проверены Lua, назначение всех ролей, переход старых отрядов и личных постов, продолжение переноса, расписания, целостность FCS и полный архив. Из 227 прежних FCS-записей 226 сохранены точно; в начальном пакете помощи заменены только ссылки спасения. Добавлены 15 частных определений. DLL и её исходники не менялись.

Kenshi в рабочей среде разработчика не запускается. Проверки API не подтверждают фактическое поведение новой иерархии в игре; для этого нужен тест на копии сохранения. При отсутствии свободной подходящей кровати перенос не может считаться гарантированным.

Исходники и GPL-3.0 нашей DLL включены в `Development/NativeBridge`; они не загружаются игрой. Остальные средства разработки доступны в репозитории.
