# KenshiShop 1.0 beta.13

Полностью закройте Kenshi и замените `mods/KenshiShop` папкой из полного ZIP. Используйте папку совместимости при установленном Legendary of Kenshi.

Дамп beta.12 показал сбой до главного меню. Функция `GameWorld::isLoadingFromASaveGame` обращалась к ещё не созданной панели `MainBarGUI`. В beta.13 проверка готовности читает флаги самого игрового мира. Она учитывает инициализацию, сброс и выход из игры.

Тест прогоняет ранние кадры, сброс и повторную загрузку имитации игрового мира. Все игровые записи FCS сверены с beta.12. Проверка запуска в самой Kenshi ещё нужна.
