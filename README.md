Текущая версия: **1.0 beta**, тег `v1.0-beta.1`. Это переход проверенной alpha.91 в бета-ветку с исправлением двух ошибок и удалением неиспользуемого кода.

## Установка

Полностью закройте Kenshi и сделайте резервную копию сохранения и прежнего мода. Замените папку `mods/KenshiShop` целиком из полного ZIP. Требования к установленным KenshiLua и KenshiLib остаются прежними; архив не заменяет игровые DLL.

`KenshiShop_LegendaryCompat` устанавливается только с **Legendary of Kenshi**, после обоих модов в списке загрузки. `Development/NativeBridge` содержит исходники и лицензию нашей DLL; в папку игры их копировать не нужно.

## Работа NPC

Призыв → доставка в выбранный город → привязка к зданию при сохранении родного города → штатные задачи Kenshi. Торговцы, охрана этажей, начальник и патруль используют нативные задачи. Охрана меняет доступные посты своего этажа раз в 30 игровых минут. Дневные магазины работают 06:00–23:00, бар и протезы круглосуточно. Патруль днём патрулирует, ночью занимает посты у башни. Сохранены Medic, Robotics и Rescue с переносом в кровать.

Защита от отсечения действует для зарегистрированных NPC 14 кастомных рас KenshiShop. В присланном игровом логе alpha.91 зафиксированы две перехваченные попытки отсечения. Уже утраченные конечности автоматически не восстанавливаются.

## Проверки и исходники

- `KenshiShop/` — игровые данные, 109 Lua-модулей, модели, текстуры и наша DLL.
- `KenshiShop_LegendaryCompat/` — необязательная совместимость.
- `Development/` — рецепты прежних сборок, проверки и исходники нативного модуля.
- `tools/package_release.py` — только полные архивы; старые отчёты и общие инструменты разработки в игровой ZIP не включаются.
- `.github/workflows/` — проверки Lua/FCS, Windows-проверка нативного модуля и выпуск ZIP.

Проверки API используют тестовые объекты и не запускают Kenshi. Реальное поведение подтверждается игровыми тестами пользователя. Сохранения и логи пользователя в репозиторий и релиз не включаются. История alpha.80–alpha.91 сохранена в Git и прежних Releases.
