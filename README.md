# KenshiShop — 1.0 beta.3

**[Скачать полный мод](https://github.com/ivanmoshuk07-sudo/KenshiShop/releases/download/v1.0-beta.3/KenshiShop_1.0-beta.3_FULL.zip)** · [Инструкция и изменения](README_BETA3_RU.md)

В разговоре с **Начальником охраны** доступны:

- Бесплатная проверка подтверждённых потерь сотрудников KenshiShop в его городе.
- Замена одного погибшего за **10 000 кат** без пересоздания выживших.
- Дополнительный отряд из **3 патрульных за 20 000 кат разово**. Днём 06:00–23:00 — посты у башни, ночью 23:00–06:00 — нативный патруль. Можно нанять несколько отрядов, пока у башни есть доступные места для постов.

Существующий дневной патруль сохраняет прежний график. Приоритеты всех ролей сохранены: **3** — защита/лечение/ремонт, **2** — спасение/перенос, **1** — работа.

## Установка

Полностью закройте Kenshi, сделайте копию сохранения и прежнего мода, замените папку `mods/KenshiShop` целиком. Загрузите сохранение и поговорите с начальником. Для совсем новой кампании сначала сделайте обычное сохранение: оно создаёт область реестра услуг.

`KenshiShop_LegendaryCompat` нужен только с Legendary of Kenshi и загружается после обоих модов. KenshiLua/KenshiLib остаются прежними, оригинальные игровые DLL не заменяются. `Development/NativeBridge` — исходники и лицензия нашей DLL, их не нужно копировать в игру.

## Сохранение и проверки

Реестр смертей, оплаченные заказы и состав дополнительных патрулей сохраняются в самой игре. Выгрузка NPC не считается смертью. Если погибший исчез до установки этой версии и подтверждения смерти нет, платная вакансия по одному лишь недостающему числу NPC не создаётся.

Мебель, товары, модели, текстуры, расовые параметры, доставка, графики и нативная защита конечностей сохранены. Дополнительные посты — настоящие LocationNode; патрулирование выполняет нативный ИИ.

Проверены Lua/API, оплата и повторные вызовы, сохранение/загрузка, пополнение отрядов, отдельные посты и FCS. Автоматические проверки используют тестовые объекты и не запускают Kenshi; новым услугам нужен игровой тест.

Исходники и исторические версии находятся в репозитории. В полный ZIP включаются игровые файлы, текущая инструкция и соответствующие исходники/лицензия DLL. Сохранения, логи и игровые бинарные файлы пользователя не публикуются.
