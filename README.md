# KenshiShop — 1.0 beta.8.2

Рабочий, солдат и принц Улья получили ванильный иммунитет к кислоте. Сохранение хранит подтверждённые потери, оплаты и состояние ухода из города.

## Установка

Полностью закройте Kenshi, сделайте копию сохранения и прежнего мода, замените папку `mods/KenshiShop` целиком. Загрузите сохранение. Для новой кампании сначала сделайте обычное сохранение — оно создаёт область реестра услуг.

`KenshiShop_LegendaryCompat` нужен только с Legendary of Kenshi и загружается после обоих модов. Мод использует установленный KenshiLua/KenshiLib. `Development/NativeBridge` содержит исходники и лицензию DLL мода.

## Услуги начальника

Вопрос о пропавших открывает список подтверждённых потерь этого города. Выберите конкретного NPC и подтвердите замену за **10 000 кат**. При проверенном составе без потерь начальник говорит «Все на месте».

Город может нанять два дополнительных отряда по три NPC. Каждый стоит **20 000 кат** разово.

1. Первый отряд с 06:00 до 23:00 стоит снаружи у полицейской башни, с 23:00 до 06:00 патрулирует город.
2. Второй отряд круглосуточно занимает три поста внутри башни.

Реплика «Уходим из города» открывает подтверждение. После ухода сотрудников KenshiShop здания и мебель города переходят игроку, а данные его найма и службы очищаются.

Проверки выполнены на моделях API и игровых данных. Проверка поведения в Kenshi остаётся за игровым тестом.
