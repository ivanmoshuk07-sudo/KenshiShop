# KenshiShop

Версии мода KenshiShop: исходная alpha.80 и доработанные alpha.81–alpha.90.

**Текущая alpha.90 — тестовая сборка.** Исправлена конфигурация штатного спасения: добавлено завершение переноски в кровать с приоритетом выше поста и подхват для уже несущих раненого NPC. Патруль работает днём 06:00–23:00, ночью получает три отдельных уличных поста у башни. Проверена существующая защита 14 кастомных рас от отсечения конечностей. Мебель, ассортимент и назначение городов сохранены. Выполнение новых задач требует игрового теста.

## Скачать и установить

Готовые ZIP находятся в разделе **Releases** репозитория:

- `FULL.zip` — полный мод. Замените папку `mods/KenshiShop` после резервного копирования.
- Начиная с alpha.84 публикуется только полный мод; отдельного UPDATE нет.
- `SHA256SUMS.txt` — контрольные суммы архивов.

`KenshiShop_LegendaryCompat` нужен только с Legendary of Kenshi и загружается после обоих модов. Требования к KenshiLua остаются как у исходной alpha.80.

Подробности: [README_ALPHA90_RU.md](README_ALPHA90_RU.md).

## Передача новых версий

1. Codex изменяет файлы в этом репозитории и запускает проверки.
2. Новая версия отмечается тегом, например `v0.3.0-alpha.83`.
3. GitHub Actions проверяет код и данные, собирает полный ZIP и публикует его как prerelease в Releases.
4. Для проверки в другом чате укажите ссылку на репозиторий и конкретный тег или commit. Доступ к закрытому репозиторию должен быть включён в подключении GitHub того чата.

Codex не отправляет сообщения в другой чат автоматически. Сборки размещаются в GitHub Releases; скачивание файлов закрытого репозитория требует входа в GitHub с доступом к нему. Репозиторий не меняет доступ к библиотеке ChatGPT.

## Структура

- `KenshiShop/` — игровые данные, Lua-скрипты, модели и текстуры.
- `KenshiShop_LegendaryCompat/` — необязательная совместимость.
- `Development/` — сборка данных и тесты.
- `tools/package_release.py` — создание ZIP из отслеживаемых файлов.
- `.github/workflows/release.yml` — автоматическая проверка и выпуск.

История `v0.3.0-alpha.80` сохраняет исходный архив без изменений. Никакие файлы установленной игры или сохранения пользователя этот репозиторий автоматически не изменяет.
