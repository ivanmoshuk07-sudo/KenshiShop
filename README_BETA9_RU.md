# KenshiShop 1.0 beta.9

Полностью закройте Kenshi. Сохраните копию текущего сохранения и замените папку `mods/KenshiShop` папкой из полного ZIP. `KenshiShop_LegendaryCompat` нужен только с Legendary of Kenshi. Для новой кампании сделайте обычное сохранение перед первым наймом.

## Начальник охраны

- **«Кто из наших сотрудников пропал?»** показывает подтверждённые потери города. Если проверка завершилась и вакансий нет, начальник отвечает «Все на месте». Из списка можно выбрать сотрудника и подтвердить замену за 10 000 кат. Выгрузка NPC сама по себе не считается гибелью.
- **Дополнительный патруль** стоит 20 000 кат за трёх NPC, оплата разовая. Днём отряд несёт службу у полицейской башни, ночью патрулирует.
- **«Уходим из города»** требует отдельного подтверждения. Отряды города уходят по штатному заданию отступления. После того как отряды покинут город, здания и мебель перейдут в собственность игрока, а городские записи службы и найма будут очищены. В сохранении остаются идентификаторы выведенных отрядов и переданных зданий, чтобы мод не восстановил их прежние привязки. Новое строительство может запустить новые службы.

Восстановление старого обрезанного реестра открывает найм, когда платёжные записи удалось прочитать целиком. При неопределённой истории оплат найм остаётся закрытым. Для выхода из города используется отдельная запись сохранения.

Проверки Lua и FCS выполнялись с тестовыми объектами. Игровая проверка движения отрядов и передачи собственности нужна на копии сохранения.
