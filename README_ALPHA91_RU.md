# KenshiShop alpha.91 — нативный запрет потери конечностей

Полный мод, тестовая сборка. Спасение и укладывание в кровать, графики патруля/магазинов/начальника и ротация охраны сохранены из alpha.90. Файл KenshiShop.mod побайтно совпадает с alpha.90; мебель, ассортимент, анатомия и HP рас не изменены.

## Что оказалось неверным в прежней проверке

В присланном сохранении охранник отряда KS Town Merchants_5 имеет кастомную расу 7117-KenshiShop.mod, медицинские ссылки на наши части тела 7001–7004 и значение `limbs = 16`: левая нога уже утрачена. У этих частей действительно записано `severance = false`. Значит, прежнее подтверждение только по FCS не доказывало реальную защиту. Название NoSever также не было доказательством.

## Новая защита

В KenshiShopNative.dll добавлены нативные перехватчики MedicalSystem.amputate и MedicalSystem.crushLimb. Для зарегистрированного NPC одной из 14 кастомных рас 7101–7106 / 7110–7117 они блокируют операцию потери конечности. Для остальных медицинских объектов исходная функция вызывается без изменения аргументов.

Контроллер регистрирует настоящий MedicalSystem NPC до проверок доставки/работы, включая раненых, бессознательных и переносимых. Протезист обычной ванильной расы не входит в список этих 14 рас. Глобальные настройки расчленения и ванильные расы не меняются.

Адреса разрешаются через публичные экспорты KenshiLib.GetRealAddress/AddHook. Числовых RVA и смещений игровых объектов в коде нет. Медицинский деструктор удаляет регистрацию перед освобождением объекта, notifyRaceChange снимает её при смене расы. Реестр защищён SRW-блокировкой; сами перехватчики не обращаются к Lua. DLL закрепляется в процессе до выхода из игры, чтобы указатели перехватчиков оставались действительными после завершения Lua.

Здоровье, кровотечение, лечение и существующие протезы не переписываются. Это предотвращение операции отсечения/разрушения, а не периодическое восстановление здоровья. **Уже отсутствующая нога из присланного сохранения автоматически не вырастет.** Для проверки новых потерь используйте копию сохранения до травмы.

## Установка и проверка

1. Полностью закройте Kenshi и сделайте копию текущего мода/сохранения.
2. Замените папку `mods/KenshiShop` целиком из FULL.zip. Особенно важен обновлённый `native/KenshiShopNative.dll`.
3. Загрузите игру; перепризыв NPC и импорт мира не требуются.
4. В логе ожидаются `NoSever91 hooks ready` и `NPC_NOSEVER91_READY native_guard=ACTIVE`. В READY также перечисляются уже отсутствующие конечности.
5. При блокировке операции появляется `NPC_NOSEVER91_BLOCKED amputations=... crushes=...`. Счётчики опрашиваются из Lua; вызовов Lua из медицинских перехватчиков нет.

`NPC_NOSEVER91_FAILED` означает, что защита не подтверждена (например, оставлен старый DLL или недоступен API хуков). Не считайте наличие имени NoSever положительным результатом. При проблеме нужен KenshiLua.log и сохранение сразу после эпизода.

## Что проверено

113 Lua-файлов, 99 сценариев API и восстановление контроллера; сохранность всех 227 FCS-записей и 49 защищённых файлов рабочего ИИ/мебели/ассортимента; Windows x64 сборка/загрузка DLL. Отдельный Windows probe проверил блокирование отсечения/разрушения для зарегистрированного объекта, передачу вызовов для обычного объекта и снятие регистрации при удалении/смене расы. **Этот probe использует тестовые публичные экспорты; Kenshi здесь не запускалась. Реальную установку перехватчиков и предотвращение потерь нужно подтвердить в игре.**

Исходники и лицензия DLL включены в Development/NativeBridge. Присланные сохранения, логи и игровые EXE/DLL в архив не включены.
