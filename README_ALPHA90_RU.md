# KenshiShop alpha.90 — спасение и смены патруля

Полный мод, тестовая сборка. Мебель, ассортимент, качество товаров, исходные 72 узла и назначение городов сохранены. Нативный DLL-модуль из alpha.89 не изменён.

## Спасение

Добавлена штатная задача 106 — FIND_BED_AND_PUT_IN — вслед за задачей 148. Этот вариант цепочки присутствует в предоставленном ванильном пакете `50354-rebirth.mod` (worker fighter indie resident); у 106 там вес 110. В новых рабочих пакетах KS90 задачи спасения и переноса в кровать имеют приоритет 3, выше поста 51 с приоритетом 2. Начальный пакет помощи 7604 также получил завершённую цепочку.

Для NPC, уже несущих раненого при обновлении, отдельный FCS-пакет добавляет только недостающее срочное продолжение 106 через штатный `AI.addAIGoalsFrom`. Это работает и пока обычная смена пакета отложена из-за переноски. Текущее действие не сбрасывается. Вмешательства в ручные приказы, принудительного сбрасывания/телепортации пациента и имитации кровати нет. Поиск доступной кровати, перенос и укладывание исполняет Kenshi. Завершение задач 70/99/100/106 блокирует перенастройку роли даже после освобождения рук.

Новый журнал `NPC_RESCUE90` различает начало переноски, текущую цель и действие, кандидат кровати, освобождение рук и отдельное подтверждение нахождения пациента в кровати. `CARRY_RELEASED` не считается доказательством успешного укладывания. `BED_CONFIRMED` требует положительного ответа штатного AI пациента. При отсутствии доступной кровати/недоступности пути Lua не выбирает обходной сценарий; лог показывает незавершённую цепочку для дальнейшей проверки.

## Патруль

- С 06:00 до 23:00 лидер использует прежнюю штатную задачу патруля 36, остальные — следование 141. Их FCS-график теперь ограничен этими часами.
- С 23:00 до 06:00 каждый из трёх патрульных получает свой настоящий наружный узел у входа в полицейскую башню. Они стоят на ночных постах; маршрута по координатам Lua не задаёт.
- Три положения вычисляются по фактическому наружному подходу двери, с учётом поворота и масштаба здания. Уличная точка начальника и посты патруля имеют отдельные handle/ключи.
- В 06:00 ночная задача удаляется один раз, и штатный пакет возобновляет патрулирование/следование. При бое, переноске, лечении и чужих приказах переход откладывается отдельно для занятого NPC.

График магазинов и начальника, разделение охраны по этажам и 30-минутная ротация охраны остаются прежними.

## Кастомные расы

Во всех 14 `KS NoSever` уже существуют четыре отдельные части тела 7001–7004 с `severance = false`. Проверены их ссылки из анатомии каждой расы; параметры сохранены. Запрет отсечения обеспечивается FCS, здоровье и повреждения не заменяются бесконечным лечением. Ванильные расы не изменены. Обычный скелет торговца протезами остаётся ванильной расой; защита относится к указанным 14 кастомным расам.

## Проверка и установка

Проверены 112 Lua-файлов, 91 сценарий API и восстановление контроллера, структура 227 FCS-записей, новые приоритеты/графики, сохранность мебели/ассортимента/городов, ссылки всех 14 рас. 218 старых FCS-записей не изменены; в старом начальном пакете помощи обновлена только цепочка спасения. Повторно проверены SHA256 и PE/экспорт/исходники DLL из alpha.89. **Kenshi здесь не запускалась: выполнение укладывания и новых ночных постов требует игрового теста.**

Полностью закройте игру, сделайте резервную копию и замените папку `mods/KenshiShop` целиком из FULL.zip, включая `native/`. Импорт мира и перепризыв NPC не требуются. Если NPC сейчас занят переноской, дождитесь завершения помощи; контроллер обновляет роль в безопасный момент.

Проверьте спасение на свободную подходящую кровать, переход 22:59→23:00 и 05:59→06:00. При проблеме пришлите KenshiLua.log; для кровати наиболее полезно сохранение непосредственно пока NPC ещё держит раненого. Основные строки: `NPC_RESCUE90`, `NPC_POST_DUTY90`, `NPC_POST_OBSERVE90`, `NPC_WORK_AUDIT90`.
