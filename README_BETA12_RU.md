# KenshiShop 1.0 beta.12

Полностью закройте Kenshi, скопируйте папку сохранения и замените `mods/KenshiShop` папкой из полного архива. Загрузите сохранение, в котором дополнительные патрули уже оплачены.

## Что обнаружено

- С beta.9 кадровый обработчик читал идентификатор через сохранённую ссылку на отряд ещё до проверки состояния мира. Новый дамп показывает сбой чтения внутри `Platoon::getPlatoonStringID` при вызове из KenshiLua. Теперь отряды разрешаются по штатным идентификаторам на текущем кадре, а работа приостанавливается при загрузке, сбросе и выходе из игры.
- В beta.11 стали доступны новые заказы в сохранении со старым повреждённым реестром. При создании каждого дополнительного отряда игра подменяла единственный слот штатного жильца башни. Игра отклоняла попытку вернуть старого жильца, поэтому назначение патрулей останавливалось. Новые отряды получают собственную привязку при прибытии. Для существующих заказов мод восстанавливает жильца башни и передаёт уже созданные отряды их штатному ИИ.
- В присланном сохранении было три оплаты по 20 000 кат и три ожидающих назначения отряда. В тесте на данных этого сохранения отряды подхватились после двух загрузок без создания новых NPC и без списаний.

Все записи FCS совпадают с beta.11. Проверки Lua, данных и сохранённого реестра выполнены вне запущенной Kenshi.
